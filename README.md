# Mod: Dead Weight - AUTO Battle

[Русский](README.md) | [English](README_EN.md)

Windows-мод автобоя для Steam-версии **Dead Weight**. Мод добавляет кнопки `AUTO` и `ONLY COMPANIONS` только во время боя: первая ведёт всю группу, вторая — только спутников, оставляя ход главного героя ручным. Режимы взаимоисключающие и запоминаются для следующего боя.

## Установка для игрока

1. Скачайте `DeadWeight_AUTO_Battle_Install_vX.Y.Z.zip` из [последнего релиза](https://github.com/Trioracks/DeadWeight-AutoBattle/releases/latest).
   `deadweight-autobattle-update.json` — служебный файл для автоматического перехода старых установок; вручную его скачивать не нужно.
2. Распакуйте архив в любую временную папку и дважды нажмите `Install-DeadWeightAutoBattle.cmd`.
3. Закройте Steam. Установщик автоматически находит игру во **всех** Steam-библиотеках пользователя: на любом диске, в том числе в дополнительных библиотеках. Если Steam не смог найти игру, он попросит вручную выбрать папку, где лежит `Dead_weight.exe`. Он создаёт `DeadWeightAutoBattle` рядом с игрой и сам настраивает постоянный параметр запуска Steam.
4. Откройте Steam и нажимайте обычную кнопку «Играть». Команда запуска также копируется в буфер как запасной вариант, но вручную вставлять её не требуется.

Установщик также создаёт ярлык `Dead Weight - AUTO Battle` на рабочем столе. Он полезен как запасной способ запуска, но для оверлея Steam предпочтительнее настройка параметров запуска.

## Автообновление

После первоначальной установки ничего перекачивать вручную не нужно. При каждом запуске через Steam-лаунчер мод:

1. получает номер последнего официального GitHub-релиза;
2. при новой версии показывает окно с номером версии и кнопками **Update now** / **Skip this version**;
3. скачивает этот же установочный архив, сверяет SHA-256 из GitHub и заменяет только `DeadWeightAutoBattle\runtime`;
4. запускает игру автоматически.

Если GitHub недоступен, хеш не совпал или обновление прервано, установленная версия остаётся на месте и запускается как обычно. Сохранения и оригинальные файлы игры не изменяются.

## Что делает AUTO

Автобой использует доступные игровые контроллеры, поэтому игра сама применяет стоимость энергии, кулдауны, анимации и эффекты. Текущая тестовая логика:

- показывает `AUTO` только в бою, а `ONLY COMPANIONS` — лишь когда в группе есть живой спутник; режимы взаимоисключающие;
- анализирует опасные клетки следующего хода, ловушки, край карты, здоровье и энергию всей группы;
- считает опасной каждую клетку, которую игра выделила для подготовленной атаки, включая дальний конец линейского удара;
- считает контроль (`web`, оглушение, обездвиживание, сон и т. п.) жёстким запретом для перемещения; если контроль уже наложен, приоритетно применяет доступное снятие эффекта у героя, спутника или из расходника;
- предпочитает безопасное добивание, отталкивание в пропасть и атаки по нескольким целям;
- при доступной атаке по врагу не тратит действие на ловушку или нейтральный объект; такие действия допустимы только когда врага сейчас затронуть нельзя;
- если остался один враг и доступно добивание, завершает бой вместо отдельной атаки ловушки;
- может оставить энергию и закончить ход на безопасной клетке вместо возврата под удар;
- учитывает способности, таланты, часть экипировки и доступные расходники;
- извлекает все активные навыки из надетого оружия и экипировки, включая эффекты с уроном со временем: готовые атакующие навыки получают приоритет, а при критическом HP и неразмеченной атаке босса сохраняет ход для отхода;
- для Клюквы учитывает дальность в начале боя и талант «Занять позицию»: после безопасного выстрела она сохраняет безопасную клетку ради усиления следующей атаки, только если полезной атаки больше нет;
- ведёт Здоровяка как хрупкого бойца на дистанции: «Выпад» используется с двух клеток, на половине HP и ниже он отходит в безопасный коридор, а «Толчок с разбега» бережёт для гарантированного сброса врага в пропасть;
- автоматический побег намеренно выключен: мод не нажимает кнопку выхода из забега.

Это активная тестовая версия. При странном ходе лучше отключить AUTO кнопкой вверху справа и продолжить вручную.

## Как сообщить об ошибке

Пришлите автору в Steam-чат:

1. полный скриншот боя с видимой кнопкой AUTO и номером версии;
2. файл `DeadWeightAutoBattle\AutoBattle.update.log`, если проблема связана с установкой или обновлением, либо последние строки с `[AUTO]` из `Godot\app_userdata\Dead_weight\logs\godot.log` для решения в бою;
3. краткие шаги воспроизведения и ожидаемый результат.

Подробный шаблон: [docs/FEEDBACK_RU.md](docs/FEEDBACK_RU.md).

## Для разработки

Исходники находятся в `mod/`. Создание релиза:

```powershell
.\mod\release\Build-Release.ps1 -Version 0.1.0
```

Артефакты создаются в `D:\Codex\Builds\Mod-Dead-Weight`, затем загружаются в GitHub Release вместе с manifest. В репозитории намеренно нет игровых EXE, PCK, сохранений и распакованных игровых файлов.
